# __APP_DISPLAY_NAME__

A CaLab web app, generated by `npm run new-app` from `apps/_template`.

```sh
# Vite dev server (builds the WASM solver first if needed)
npm run dev __APP_DIR__
# Vitest
npm test -w apps/__APP_DIR__
```

What is here:

- `src/index.tsx`: startup (tutorial storage key, community auth store,
  analytics session), the same sequence as CaTune and CaDecon.
- `src/App.tsx`: the magic-link sign-in callback, the shared import flow
  (`ImportOverlay` from `@calab/ui/import` on the store in
  `src/lib/data-store.ts`), and a dashboard once data is loaded.
- `src/components/TraceView.tsx`: a placeholder result view (a cell picker and
  a `TraceOverview` chart). Replace it with your analysis.
- `src/__tests__/App.test.tsx`: renders the app through the import flow.

The `calab` block in `package.json` controls the landing-page card and the
`apps.json` manifest. See `docs/NEW_APP.md` at the repo root.
